# Navigation and Localized Screenshots

## Bottom navigation

The mobile bottom tab bar contains four pages:

1. Dashboard: projects and workspace overview.
2. Terminal: project terminal sessions.
3. Community: posts and reusable components.
4. Settings: account, appearance, integrations, billing, and language.

## Other main pages

The app also exposes project detail (Overview, Code, Database, Storage, Analytics,
API, Payment, and Deploy History), Profile, Projects, Orders, Docs, API Docs,
Notifications, Invites, GitHub integration, Help & Support, and **Chat with AI**.

Chat with AI is available from a project at `/projects/:id/chat` and is included
in every localized screenshot set.

## Screenshot sets

The ignored `docs/localized-screenshots/<locale>/` directories contain the six
core captures for each supported locale:

- `home-screen.png`
- `terminal-screen.png`
- `community-screen.png`
- `my-page-screen.png`
- `project-detail-screen.png`
- `chat-with-ai-screen.png`

Regenerate them with:

```sh
../.venv/bin/python tool/capture_store_screens.py \
  --all-languages --skip-chat-seed --fast --content-wait-seconds 10 \
  --output-dir docs/localized-screenshots
```

To refresh only the API-backed project and chat captures, use
`--only-screens project,chat`. The default capture project is the populated
`africa-client-dev-system`, which includes a full project overview and rich
multi-turn chat history.

Device-sized exports are generated from those localized captures into the
existing App Store material locations:

```sh
bash tool/export_device_screenshots.sh
```

Each device directory contains `screenshots/<locale>/` with six PNGs at the
requested dimensions. The iPhone 6.5 (1284x2778) and iPad 13 (2064x2752)
assets are device-sized exports of actual app captures.

The Apple Watch Ultra 3 assets (422x514) are dedicated companion UI mockups,
generated by `tool/generate_watch_companion_mockups.py`. They are not resized
iPhone pages, but they are also not simulator captures: this repository does
not currently contain a watchOS app target. A real watchOS target and simulator
capture are required before submitting them as Watch App Store screenshots.
The adjacent `watch-mockup-manifest.json` records this distinction explicitly.

To build App Store review promo posters and six-screen preview strips from the
same captures:

```sh
bash tool/generate_appstore_promos.sh
```

Outputs are written under each device's `promos/<locale>/` directory.
